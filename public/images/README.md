# Bilder till Portfolio V2

Lägg bilderna direkt i den här mappen. Koden provar automatiskt följande filändelser:

`webp`, `avif`, `jpg`, `jpeg`, `png` samt versala JPG/JPEG/PNG.

Grundnamnet måste vara exakt enligt listan nedan. Exempel: `portrait.jpg`, `fiber.png` eller `trustscribe.webp`.

## Bildlista

| Grundnamn | Användning | Rekommenderat format |
| --- | --- | --- |
| `portrait` | Porträtt i hero-sektionen | Stående 4:5, minst 1200 × 1500 px |
| `hts` | Teknikprogrammet i tidslinjen | Liggande 4:3 eller 16:10 |
| `fiber` | Arbetet som fibertekniker | Liggande 4:3 eller 16:10 |
| `te4` | Gymnasieingenjör/NTI i tidslinjen | Liggande 4:3 eller 16:10 |
| `trustscribe` | TrustScribe-projektet och tidslinjen | Liggande skärmbild, helst 16:10 |
| `malta` | Praktiken på Ascencia Malta | Liggande 4:3 eller 16:10 |
| `zynq` | Praktiken på ZYNQ Media Group | Liggande 4:3 eller 16:10 |
| `campaignforge` | CampaignForge/CopyForge-case study | Liggande skärmbild, helst 16:10 |
| `one-percent` | 1Percent-case study | Liggande skärmbild, helst 16:10 |

HEIC och HEIF måste konverteras till något av formaten ovan. WebP rekommenderas för bäst kombination av kvalitet och filstorlek. Försök hålla varje bild under 700 kB.
