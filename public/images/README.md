# Bildplatser

Webbplatsen använder just nu designade platshållare. Lägg framtida bilder här och byt `image`-fältet i `src/content.js`.

Rekommenderade filer:

- `eliah-portrait.webp` — stående porträtt, minst 1200 × 1500 px
- `fiber.webp` — arbete som fibertekniker
- `trustscribe.webp` — skärmbild eller miljöbild
- `campaignforge.webp` — produktskärmbild
- `one-percent.webp` — produktskärmbild
- `malta.webp` — praktikbild
- `zynq.webp` — praktikbild
- `og-image.webp` — delningsbild, 1200 × 630 px

Använd helst WebP eller AVIF och håll varje bild under cirka 500 kB.
